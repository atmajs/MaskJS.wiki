## `1` `debugger`

This helper component can hit the breakpoint on render and from there you can inspect the components tree, and also the model.
```mask
ul > each(users) {
	debugger;
	li > '~[name]'
}
```

## `2` `log`

This helper component can output the expressions result to the console.
```mask
ul > each(users) {
	log (id, name);
	li > '~[name]'
}
```
